I Campi con Default   :  Nessuno

I CAMPI DEL RECORD in Ordine ALFABETICO


MetaFieldDescriptorIdINTN° Identificativo ((CHIAVE AUTOMATICA UNIVOCA)) della Singola Riga di Menù Campo Obbligatorio. Viene Impostata AUTOMATICAMENTE dal Sistema e NON E' MODIFICABILE da parte degli Utenti del Sistema. Nessun Controllo specifico
MetaDescriptorId

 INT N° identificativo della Vista Logica a cui appartengono i relativi Campi. Campo Obbligatorio.     Viene contralloto che esista nella Tabella MetaDescriptor
FieldName
 NVARCHAR(MAX)
 Nome del Campo della relativa Vista Logica cui si riferiscono i Dati di questo Record.  Nessun Controllo specifico ma deve essere inserito manualmente in modo corretto così come è stato definito nella relativa struttura di quella Vista Logica cui si riferisce.e
GridViewDataType
 INT Tipo di Campo di quella Vista da visualizzare nella DataGrid Principale e nella Parte di EDIT.Campo Obbligatorio
Può assumere i seguenti valori
       0  = DataText             [Campi DB definiti NVarChar]
       1  = DataCheck          [Campi DB definiti Bit]
       2  = DataDate            [Campi DB definiti Date e/o SmallDateTime]
       3  = DataTime            [Campi DB definiti Time(x)]
       4  = DataComboBox  [Campi DB definiti NVarChar e/o Int gestiti poi a Video con ComboBox]
       5  = DataSpin             [Campi DB definiti Numerici (Int,Double, Float)]
 IsAvailable
 BIT Definisce se quel campo di quella Vista è Disponibile o meno nell'Elenco dei Campi usabili.(Mascherina di Customization)  Campo Obbligatorio 
Può assumere i seguenti valori:
     TRUE   = significa che quel campo viene mostrato nella DataGrid Principale
     FALSE = significa che quel campo NON viene mostrato nella DataGrid Principale
  IsVisible
 BIT Definisce se quel campo di quella Vista è visibile o meno nella DataGrid Principale Campo Obbligatorio 
Può assumere i seguenti valori:
     TRUE   = significa che quel campo viene mostrato nella DataGrid Principale
     FALSE = significa che quel campo NON viene mostrato nella DataGrid Principale
IsVibile_EditFormSettings
 BIT Definisce se quel campo di quella Vista è visibile o meno nella parte di EDIT Campo Obbligatorio 
Può assumere i seguenti valori:
     TRUE   = significa che quel campo viene mostrato nella parte di EDIT
     FALSE = significa che quel campo NON viene mostrato nella parte di EDIT
IsReadOnly
 BIT Definisce se quel campo di quella Vista è MODIFICABILE o meno nella parte di EDIT Campo Obbligatorio 
Può assumere i seguenti valori:
     TRUE   = significa che quel campo è MODIFICABILE nella parte di EDIT
     FALSE = significa che quel campo NON è MODIFICABILE nella parte di EDIT
VisibleIndex
 INT Definisce la posizione della Data Grid Principale in cui verrà visualizzato quel Campo
Width
 NVARCHAR(MAX) Grandezza in percentuale di quel Campo di quella Vista nella Data Grid Principale
NOTA BENE : va inserita nel seguente formato XX% (con il simbolo di % dopo la misura della Grandezza)
Mask
 NVARCHAR(MAX) Eventuale Maschera di proposta di Inserimento/Modifica per i soli campi di DATATEXT (valore 0 in GridViewDataType)  da usare per visualizzare quel Campo di quella Vista nella parte di EDIT.
Vedi anche IncludeLiterals
IncludeLiterals
 INT Definisce per i soli Campi di DATATEXT (valore 0 in GridViewDataType) quali caratteri includere nel salvataggio del valore inserito in quel campo (vedi documentazione DevExpress (http://documentation.devexpress.com/#AspNet/DevExpressWebASPxEditorsMaskSettings_IncludeLiteralstopic):
Può assumere i seguenti valori:
        All                    = 1  Salva nel campo del DB TUTTI I caratteri specificati nell'eventuale MASK
        None                = 2  Salva nel campo del DB SOLO i caratteri inseriti a video dall'Utente (non quelli della MASK)
        DecimalSymbol = 3  Salva nel campo del DB ANCHE i simboli dei decimali della MASK
DisplayFormatString
 NVARCHAR(MAX) Definisce per i soli Campi di DATADATE (valore 2 in GridViewDataType) il Formato di EDIT di quel Campo di quella Vista .
Può assumere i seguenti Valori:
        Date         = 0  Visualizza il Campo come DATA
        DateTime  = 1  Visualizza il Campo come DATA E ORA
        Time         = 2   Visualizza il Campo come ORA
        Custom     = 3   Visualizza il Campo in Modo CUSTOM (NON gestita)
HorizontalAlign
 INT Definisce il Tipo di Allineamento ORIZZONTALE di quel Campo di quella Vista. Campo Obbligatorio 
Può assumere i seguenti VAlori
       NotSet    = 0  Il Campo non viene allineato orizzontalmente
        Left        = 1  Il Campo viene allineato a SINISTRA
        Center    = 2  Il Campo viene allineato al CENTRO
        Right      = 3  Il Campo viene allineato a DESTRA
        Justify     = 4  Il Campo viene GIUSTIFICATO
EditFormat
 INT Definisce per i soli Campi di DATADATE (valore 2 in GridViewDataType) come viene FORMATTATO quel Campo di quella Vista Campo Obbligatorio 
Può assuemre i seguenti valori:
        Date        = 0
        DateTime = 1
        Time        = 2
        Custom    = 3
DecimalPlaces
 INT Definisce per i soli Campi di DATASPIN (valore 2 in GridViewDataType) il Numero di Decimali per quel Campo di quella Vista Campo Obbligatorio

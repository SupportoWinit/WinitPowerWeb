Il Programma di Gestione delle Traduzioni in LINGUA

Questo Programma (che viene usato SOLO dal Personale Tecnicio della WINIT) gestisce
  • ESTRAZIONE DI TUTTE le COSTANTI relative a
    • quanto contenuto nei singoli File xxxx.resx relativi a:
      • tutte le Form Form (frmXxxxxxx.resx) presenti nel Sistema
      • tutti i Report (crXxxxxxxx.resx) presenti nel Sistema
    • quanto contenuto nelle Resources.resx di Sistema relative a
      • tutte le Costanti NON riferite alle Forms ed ai Reports
  • IMPORTAZIONE DELLE TRADUZIONI IN LINGUA DI TUTTE LE COSTANTI relative
    • quanto contenuto nei singoli File xxxx.resx relativi a:
      • tutte le Form Form (frmXxxxxxx.resx) presenti nel Sistema
      • tutti i Report (crXxxxxxxx.resx) presenti nel Sistema
    • quanto contenuto nelle Resources.resx di Sistema relative a
      • tutte le Costanti NON riferite alle Forms ed ai Reports
Il Programma al momento del Lancio propone la seguente Maschera iniziale:

 NOTA:  Il Nome del Percorso e dell'Estensione del File sia di Input sia di Output NON sono Modificabili mentre il Nome del File viene proposto secondo quanto previsto dallo standard ma può essere modificato da parte dell'operatore (anche se si sconsiglia di farlo).
Ricordiamo che i Nomi Standard sono :
          • Costanti_Estratte_da_Resx.csv
  • Costanti_Estratte_Da-Resource.csv
  • Costanti_Tradotte_per_Resx.csv
  • Costanti_Tradotte_per_Resource.csv
L'Operatore sceglie il Tipo di Operazione che intende eseguire ed il sistema a fronte di quanto richiesto provvede ad abilitare il corrispondente TASTO DI LANCIO
                                                      EXPORT DELLE COSTANTI
     relative alle FORMS/REPORTS                 NON  relative alle FORMS/REPORTS

                      



 
Crea il file Costanti_Estratte_da_Resx.csv     Crea il file Costanti_Estratte_Da-Resource.csv  
NOTA BENE : Essendo entrambi questi 2 File di Tipo RIGENERATIVO ovvero vengono ad ogni successivo lancio
  •     Cancellati (se già esistenti)
  •     Scritti ex Novo con lo stesso Nome
SENZA CHE IL SISTEMA emetta alcun Messaggio di avvertimento , prima di Cancellare l'eventuale File esistente, in quantio si apsetta, come previsto da quanto indicato nella Gestione In Lingua si apsetta che , per evitare inconsapevoli perdite durante l'eventuale lavoro di traduzione eventualmente in corso, le Traduzioni vengano ssempre eseguite su apposite COPIE (create manualmente dal responsabile della Traduzione in quella specifica lingua) del suddetto File che , per identificarle in modo univoco e standard, si chiameranno :
  •  Costanti_In_Traduzione_Resx.csv
  • Costanti _In_Traduzione_Resource.csv
E' quindi compito del Responsabile delle Traduzioni di provvedere, appena eseguita una estrazione delle Costanti, procedere a rinominare il File estratto secondo quanto prevsito dalla gestione delle Traduzioni in Lingua.

Una volta terminata la Traduzione  il corrispondente file contenente le Costanti in Traduzione, verrà rinominato a cura del responsabile della traduzione rispettivamente in
  •     Costanti_Tradotte_per_Resx.csv
  •     Costanti_Tradotte_per_Resource.csv
Questi 2 Files , che contengono il risultato delle traduzioni, anche parziale, viene quindi importato nel Sistema scegliendo la relativa opzione a video:
                                                EXPORT DELLE COSTANTI
     relative alle FORMS/REPORTS                 NON  relative alle FORMS/REPORTS





 

Importa Costanti_Tradotte_per_Resx.csv     Importa Costanti_Tradotte_per_Resource.csv
Il programma provvede quindi
  • partendo dalle Costanti presenti nel Sistema 
a ricercarle nel corrispondente File (Costanti_Tradotte_per_Resx.csv e/o Costanti_Tradotte_per_Resource.csv)  indicato a video ed a sostituirne (quando DIVERSO da BLANKS nel file di Input) il valore della specifica lingua xx-XX nel corrispondente file Rsx e/o Resource della lingua corrsipondente

      • valore in inglese       <> blank  --> Agg Costante nel file NomeForm/Report.en_GB.resx
      • valore in tedesco      <> blank --> Agg Costante nel file NomeForm/Report.de_DE.resx  
      • valore in spagnolo    <> blank --> Agg Costante nel file NomeForm/Report.es_ES_IT.resx
      • valore in francese     <> blank --> Agg Costante nel file NomeForm/Report.fr_FR_IT.resx
      • valore in russo          <> blank --> Agg Costante nel file NomeForm/Report.xx-XX.resx
      • valore in Ass.Domic <> blank ---> Agg Costante nel file NomeForm/Report.X1_X1.resx
      • valore in Lingua-A   <> blank  ---> Agg Costante nel file NomeForm/Report.aa_AA.resx
      • valore in Lingua-B    <> blank ---> Agg Costante nel file NomeForm/Report.bb_BB.resx
  • file Costanti_Tradotte_per_Resources.csv
    • Nome Form/Report di Provenienza
    • Nome Costante
      • valore in italiano      <> blank   --> Agg Costante nel file NomeForm/Report.it_IT.resx
      • valore in inglese       <> blank  --> Agg Costante nel file NomeForm/Report.en_GB.resx

      • valore in Lingua-B    <> blank ---> Agg Costante nel file NomeForm/Report.bb_BB.resx

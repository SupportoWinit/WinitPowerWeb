LA GESTIONE dell'HELP

  • L’HELP è scritto in HTML con il Programma KOMPOZER (Free)
  • L’Help viene gestito a livello di:
    • Singola Maschera
    • F1 : Singolo Campo dellla Singola Maschera

1) La Gestione delle CHIAMATE all’HELP della SINGOLA MASCHERA è fatta dall'interno del codice Java che gestisce il Tasto Funzionale di HELP

  • PowerWeb
    • GridMasterPage.master
      • <dx:ASPxButton UseSubmitBehavior="false" ID="btnHelp" runat="server" CssClass="headerButtons" AutoPostBack="false">
        • <ClientSideEvents Click="function(s, e) {redirectOnHelpPage();}" />
          • <Image Url="~/Icons/Help/Help.png"></Image>
        • </dx:ASPxButton>
    • che richiama a sua volta (sempre nella stessa Pagina Java) la Funzione di redirectonHelpPage che imposta il percorso in cui cercare l'Help
      • function redirectOnHelpPage() {
                    window.open(getBaseURL() + 'HelpPages/PAGES/_' + getCurrentPageNoExtNoPage() + '_PAGE.html', '_blank');        } 
    • che richiama a sua volta (sempre nella stessa Pagina Java)  la Funzione getCurrentPageNoExtNoPage che ricava il Nome della Pagina da cui viene chiamato l'Help della Pagina
      • function getCurrentPageNoExtNoPage()
        • { var sPage = getCurrentPage();
        • return sPage.substr (0, sPage.lastIndexOf('Page')); }
    • che richiama a sua volta  (sempre nella stessa Pagina Java)  la Funzione getCurrentPagee che ricava
      •  function getCurrentPage()
        • {var sPath = window.location.pathname;
        • var sPage = sPath.substring(sPath.lastIndexOf('/') + 1);
        • return sPage; }

Il Testo di HELP della Pagina  viene quindi cercato nella Cartella PAGES

  • PowerWeb
    • HelpPages
      • PAGES
        • costruendone il Nome del Singolo Help della Singola pagina da cui viene richiamato
        • con il Nome della Pagina + "_Page.html"
          • XXXX_Page

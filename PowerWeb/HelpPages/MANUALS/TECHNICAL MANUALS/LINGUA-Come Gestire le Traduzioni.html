Come Gestire le Traduzioni nelle diverse LINGUE

La Gestione delle Lingue prevede la Gestione delle Traduzioni in Lingua delle Costanti contenute
  • in COMMON\ PowerWebResources.resx ovvero
Queste Costanti vanno estratte dal Sistema lanciando l'Apposito Programma di Gestione delle Lingue (vedi Manuale LINGUE - Le Nomenclature delle Risorse.html) che provvede ad estrarle dal Sistema ed a creare , in base all'opzione scelta,  i seguenti 2 Files csv:
  • Costanti_Estratte_da_Resx.csv
  • Costanti_Estratte_Da-Resource.csv
che hanno entrambi il seguente tracciato:
  • Provenienza                                  Nome della Form/Report/Resources di Provenienza
  • Nome Costante ;                          Nome Standard della Costante nella Form/report/Resouces
    • Valore in Italiano
    • Valore in Inglese
    • Valore in Tedesco
    • Valore in Spaganolo
    • Valore in Francese
    • Valore in Russo
    • Valore Assist.Domicial.
    • Valore da Definire-A
    • Valore da Definire-B
Essendo entrambi questi 2 File di Tipo RIGENERATIVO ovvero vengono ad ogni successivo lancio
  •     Cancellati (se già esistenti)
  •     Scritti ex Novo con lo stesso Nome
occorre che, per evitare inconsapevoli perdite durante l'eventuale lavoro di traduzione eventualmente in corso, le Traduzioni vengano eseguite su apposite COPIE (create manualmente dal responsabile della Traduzione in quella specifica lingua) del suddetto File che , per identificarle in modo univoco e standard, si chiameranno :
  •  Costanti_In_Traduzione_Resx.csv
  • Costanti _In_Traduzione_Resource.csv
Una volta terminata la Traduzione  il corrsipondente file verrà rinominato a cura del responsabile della traduzione rispettivamente in

    Costanti_Tradotte_per_Resx.csv
    Costanti_Tradotte_per_Resource.csv
Il Contenuto di questi 2 Files , contenenti il risultato delle traduzioni, anche parziale, va poi importato nel Sistema lanciando l'Apposito Programma di Gestione delle Lingue (frmGestioneXml) che provvederà
  • partendo dalle Costanti presenti nel Sistema 
a ricercarle nel File (Costanti_Tradotte_per_Resx.csv e/o Costanti_Tradotte_per_Resource.csv)  indicato a video ed a sostituirne (quando DIVERSO da BLANKS nel file di Input) il valore della lingua x nel corrispondente file Rsx e/o Resource della lingua corrsipondente
  • file Costanti_Tradotte_per_Resx.csv
    • Nome Form/Report di Provenienza
    • Nome Costante
      • valore in italiano      <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.it_IT.resx
      • valore in inglese       <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.en_GB.resx
      • valore in tedesco      <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.de_DE.resx  
      • valore in spagnolo    <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.es_ES_IT.resx
      • valore in francese     <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.fr_FR_IT.resx
      • valore in russo          <> blank   -------> Aggiorna Valore della Costante nel fileNomeForm/Report.xx-XX.resx
      • valore in Ass.Domic <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.X1_X1.resx
      • valore in Lingua-A   <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.aa_AA.resx
      • valore in Lingua-B    <> blank   -------> Aggiorna Valore della Costante nel file NomeForm/Report.bb_BB.resx
NOTA BENE :  l'Aggiornamento viene eseguito partendo SEMPRE dalle SOLE Costanti presenti nel Sistema per cui anche se nel File delle Costanti_Tradotte che viene importato sono eventualmente presenti delle Costanti che NON sono più presenti nel sistema (perchè nel frattempo il sistema è stato modificato eliminandone alcune di obsolete e/o modificandone il Nome standard) NON SUCCEDE NULLA in quanto vengono ignorate proprio perchè si parte SEMPRE da quelle presenti attulmente nel Sistema.

DOVE DISABILITARE I SINGOLI TABS/CAMPI DI UNA PAGE

Nella Tabella TAB_EDITFORMTEMPLATE è possibile per ogni Diversa ENTITA'  per la quale vengono gestiti gli EditFormTemplate
paremetrizzare il sistema in modo che vengano eventualmente DISABILITATI
    - uno o + di uno dei TABS
    - uno o + di uno dei Singoli Campi

previsti nella relativa Form di Editing di quella specifica Form

Per fare ciò basta inserire nella suddetta Tabella TAB_EDITFORMTEMPLATE un record con
  • il campo Entity_Tab_EditFormTemplate intestato a quella ENTITA' (es Cant, e/o COL:NOTE e/o Fru_Cant ecc)
  • associandoci 
    • nel campo Tabs_Tab_EditFormTemplate l'ventuale elenco dei NOMI DEI TABS da DISABILITARE
      • separandoli uno dall'altro con il carattere | (pipe)
    • nel campo Fields_Tab_EditFormTemplate l'eventuale elenco dei NOMI DEI CAMPI DA DISABILITARE
      • separandoli uno dall'altro con il carattere | (pipe)
E' possibile disabilitare per ogni singolo Entità nella corrispodnente Pagina di Gestione di questa Entità:
  •     solo determinati TAB
  •     solo determinati Campi
  •     sia determinati Tab e determinati Campi
I Nomi delle Entità per le quali è possibile Disabilitare Singoli TABS e/o Singoli Campi sono PRECARICATI all'interno della Tabella Tab_EditFormTemplate e per alcuni di essi sono già preimpostati alcuni TABS che ATTUALMENTE NON vengono ancora Utilizzati all'interno di POWER WEB

Per conoscere l'elenco delle Entità con i relativi Tabs e relativi Nomi dei Campi Video eventualmente DISABILITABILI consultare il tracciato Record della Tab_EditForm_Template.

La Gestione a livello di codice viene fatta in:
  • POWER WEB
    • MODULE
      • EditDictionaryManager
        • public static class EditDictionaryManager
tramite le due routine
  •  private static bool IsEFTTabDisabled (Tab_EditFormTemplate currentEFT, string tabName)
    • restituisce TRUE se quel EFTT (EditFormTemplateTab)ovvero quel TAB è disabilitato
  •  private static TabPageItemExtended GetEFTField (Tab_EditFormTemplate currentEFT, string fieldName, TabPageItemFieldTypeEnum PIFEnum = TabPageItemFieldTypeEnum.None)
    • restituisce TRUE se quel Field ovvero quel CAMPO è disabilitato

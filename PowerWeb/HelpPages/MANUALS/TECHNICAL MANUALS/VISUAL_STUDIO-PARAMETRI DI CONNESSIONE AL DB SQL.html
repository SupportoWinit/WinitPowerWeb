Nel caso in cui si volesse utilizzare una COPIA LOCALE installata sul PC LOCALE
allora i Parametri di Connessione sono:











      Password : Winit2002






in questo caso occorre modificare il contenuto html della Pagina WEB.config

verificare se esiste ed EVENTUALMENTE DISATTIVARE la prima riga
<!--add name="PowerWebEntities" connectionString="Integrated Security=SSPI;Persist Security Info=False;Initial Catalog=Power;Data Source=." />-->
uindi disattivare la riga di connessione standard
<add name="PowerWebEntities" connectionString="Data Source=192.168.1.1\SQLEXPRESS2008;Initial Catalog=Power;Persist Security Info=True;User ID=sa;Password=Winit2002;MultipleActiveResultSets=True"/>
aggiungendoci all'inizio:i <!-- e in fondo --> e cambiandola in :
<!--<add name="PowerWebEntities" connectionString="Data Source=192.168.1.1\SQLEXPRESS2008;Initial Catalog=Power;Persist Security Info=True;User ID=sa;Password=Winit2002;MultipleActiveResultSets=True"/>-->
e riattivare /aggiungere se manca) la riga di connessione locale
<!--<add name="PowerWebEntities" connectionString="Data Source=MASSIMO-PC\SQLEXPRESS;Initial Catalog=Power;Persist Security Info=True;User ID=sa;Password=Winit2002;MultipleActiveResultSets=True" />-->
togliendo da davanti <!-- e dal fondo --> e cambiandola quindi in
<add name="PowerWebEntities" connectionString="Data Source=MASSIMO-PC\SQLEXPRESS;Initial Catalog=Power;Persist Security Info=True;User ID=sa;Password=Winit2002;MultipleActiveResultSets=True" />

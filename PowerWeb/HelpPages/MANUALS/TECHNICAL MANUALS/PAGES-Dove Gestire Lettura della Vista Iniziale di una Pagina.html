Dove Gestire la Lettura della Vista Iniziale di una Pagina

  • Visualizzazione Specifica x Singolo Utente

Quando si apre una Pagina che ha una DataGrid iniziale , il sistema verifica se esiste nella Tabella TAB_DATAGRID
uno o più record che abbiano :
  • NOME_DATAGRID = Nome della DataGrid principale associata a quella pagina    
  • CODICE_UTENTE = Utente_Id collegato
Nel caso ne esista più di uno propone x Default quello con Codice_Utente = Utente_ID collegato e DATA_LAYOUT_DATAGRID + RECENTE

Questo per proporre come COLONNE DI DEFAULT l'elenco di Colonne eventualmente inserito da quello specifico Utente in modo che ogni Utente
possa crearsi una propria Visualizzazione di Default

Per creare una propia Visualizzazione a livello di Singolo Utente (Utente_ID <> Null) basta modificare a Video la Struttura delle Colonne della Data Grid
e salvarla con un Nome a scelta (evitare di Chiamarla DEFAULT che è una parola riservata)

Le Visualizzazioni PERSONALIZZATE x UTENTE sono identificate (nella Finestra di selezione Video) da un Simbolo Utenti davanti al Nome della Visualizzazione

  • Visualizzazione Specifica x Azienda (valida in assenza della precedente)

NEL CASO IN CUI NON ESISTA nessun Record per quello specifico Utente allora cerca l'eventuale Record della Tabella
TAB_DATAGRID che abbia
  • NOME_DATAGRID = Nome della DataGrid principale associata a quella pagina    
  • CODICE_UTENTE = Null
Nel caso ne esista più di uno propone x Default quello con Codice_Utente = Null e DATA_LAYOUT_DATAGRID + RECENTE

Questo per proporre come COLONNE DI DEFAULT l'elenco di Colonne eventualmente inserito da quella Azienda in modo che ogni Utente
che NON abbia una propria Visualizzazione di Default utilizzi quella di Defaul creata dall'Azienda Stessa al posto di quella Standard proposta
da Winit

Per creare una Visualizzazione a livello Aziendale (Utente_ID = Null) occorre essere un Utente particolare che abbia un apposita Autorizzazione
a farlo definita nella TAB_AUT, ovvero che abbia un apposito Record nella TAB_AUT con
  • FUNZ_AUT >= al Livello definito come Livello ADMIN in (normalmente è 10)
  • NOME_PANNELLO = NULL
  • FUNZ_ID = NULL
  • UTENTE_ID = Utente_Id con cui quell'Utente è identificato nela Tabella UTENTI           
Quando un Utente , con queste caratteristiche , (normalmente sarà l'Utente ADMIN a farlo)  modifica a Video la Struttura delle Colonne della Data Grid
 e la salva con un Nome a scelta (evitare di Chiamarla DEFAULT che è una parola riservata) questa struttura viene memorizzata

Le Visualizzazioni PERSONALIZZATE x UTENTE sono identificate (nella Finestra di selezione Video) da un Simbolo Utenti davanti al Nome della Visualizzazione

  • Visualizzazione Standard WINIT (valida in assenza delle 2 precedenti)

NEL CASO IN CUI NON ESISTA nessun Record nella Tabella TAB_DATAGRID per quella specifica DataGrid (con o senza Codice Utente)
allora viene proposta automaticamente una Visualizzazione di DEFAULT STANDARD , predisposta da WINIT come Versione di Default Standard
per tutti gli Utenti che non abbiamo creato o una propria Visualizzazione specifica per sè stessi o una Visualizzazione Aziendale.

NOTA BENE : la Visualizzazione di DEFAULT preparata da WINIT viene gestita in base al contenuto del Codice presente in
  • SOLUZION "POWER WEB"
    • POWERWEB
      • MODULES
        • NomePagina.ascx
          • usando i Campi che in questo modulo NON hanno VISIBLE=FALSE                   
Le Visualizzazioni STANDARD proposte da WINIT PERSONALIZZATE x UTENTE sono identificate (nella Finestra di selezione Video) dal nome
DEFAULT (che è quindi una parola riservata e non va usata mai per creare nessuna visualizzazione Aziendale e/o x Utente)

NOTA BENE : ATTUALMENTE NON VIENE CONTROLLATO
                            che una eventaule Visualizzazione x UTENTE e/o x AZIENDA venga o meno chiamata DEFAULT.
                                        Occorre aggiungere il relativo Controllo e Messaggio
                           mentre viene controllato che la Visualizzazione abbia un Nome (diverso da Blank) ma non viene emesso il relativo messaggio
                           di errore quando non la si identifica con nessun nome in fase di salvataggio
                                        Occorre aggiungere il relativo Messaggio

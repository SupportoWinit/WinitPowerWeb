COME RIPRISTINARE/CREARE UN DATA BASE DALLA COPIA DI BACKUP

E' possibile CREARE UN DATABASE
  •     partendo dalla COPIA DI BACKUP di POWER 
    • anche creandone uno con un Nome Diverso
  •     partendo dallo SCRIPT di Generazione del DataBase
    • anche creandone uno con un Nome Diverso
  • Aprire SQLSERVER
    • se si vuole RICREARE UN DataBase ESISTENTE DALLA COPIA DI BACKUP
      • cliccare su DataBase
        • cliccare con il Tasto DX sul Nome del dataBase da ELIMINARE
          • scegliere l'opzione CANCELLA
    • se si vuole CREARE un NUOVO DataBase DA UN DATA BASE ESISTENTE DALLA COPIA DI BACKUP
      • Cliccare con tasto DX su DataBase
        • Scegliere RIPRISTINA DATABASE
  





    Scegliere coma ORIGINE ---> POWER

 

    Inserire il Nome del Nuovo DataBase da Creare

    Lasciare imporstato di Ripristinare dall'Ultimo Backup


    Lasciare selezionate le opzioni
    - Ripristina da Power Completo
    - Ripristina da Power Differenziale















   

 




Espandere la Colonna di RIPRISTINA COME  e CAMBIARE il NOME DEI DUE FILES con il Nome del NUOVO DATABASE che si sta creando.

RIGENERAZIONE COMPLETA DEL DATA BASE DA UNO SCRIPT

Quando si deve ricreare l'intero DATABASE partendo dallo Script che ne contiene
tutta la relativa Struttura occorre:
  • COLLEGARSI AL GESTORE SQL
    • CANCELLARE LA PRECEDENTE VERSIONE DI POWER
      • Tasto DX
      • ELIMINA
      • Premere CONFERMA
    • CREARE IL NUOVO DATABASE
      • es. POWER e/o POWERNEW
    • APRIRE LO SCRIPT SQL RICEVUTO
      • Cancellare TUTTE le PRIME RIGHEdalla Riga
        • USE [master]
          GO
          /****** Object:  Database [Power]    Script Date: 08/08/2012 09.22.08 ******/
      • Alla riga
        • EXEC sys.sp_db_vardecimal_storage_format N'Power', N'ON'
          GO
      • Nel caso si voglia RICREARE il DATA BASE POWER
        • Lasciando quindi le righe dalla:
          • USE [Power]
            GO
            /****** Object:  Table [dbo].[Cant]    Script Date: 08/08/2012 09.22.08 ******/
      • Nel caso si voglia RICREARE un NUOVO DATABASE
        • Modificare la righe:
          • USE [Power] in USE [NOME NUOVO DATABASE]
        • Lasciando invariate tutte le righe suguenti
          • GO
            /****** Object:  Table [dbo].[Cant]    Script Date: 08/08/2012 09.22.08 ******/
    • Lanciare la QUERY di Creazione

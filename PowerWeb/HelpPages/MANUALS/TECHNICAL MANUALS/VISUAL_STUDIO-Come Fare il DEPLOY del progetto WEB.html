PUBBLICAZIONE PROGETTO SU WEB

Quando si vuole "pubblicare" sul WEB la nuova versione del progetto POWER WEB occorre esguire i seguenti passi:

  • Aprire Visual Studio
    • scegliere il progetto PowerWeb
      • dalla finestre di Esplora Soluzioni scegliere
        • POWERWEB
          • cliccare con Tasto DX del Mouse
            • Scegliere PUBBLICA
  • compare la seguente Maschera

  Scegliere PROFILO
   
    Se viene già proposto il Profilo TestVersion
    lasciare il Profilo proposto.
    Altrimenti scegliere (se esiste) il Profilo TestVersion
    Altrimenti (se none siste) creare il Profilo TestVersion










   Scegliere CONNESSIONE
   
    Se viene già proposto il Metodo File system
    lasciare il Metodo proposto.
    Altrimenti scegliere il Metodo File system   
    Se viene già proposto il Percorso di Destinazione
    - Inserire un percorso LOCALE Temporaneo (se su PC PERSONALE)
        - C:\Massimo\Power_Web\Deploy\
oppure direttamente quello della pubblicazione FINALE (se su SERVER WINIT)
    \\192.168.1.1\winit\AAA_AREA_SVILUPPO_SW\SW APPLICATIVO\
            PowerWeb\PowerWeb (versione utilizzata da IIS)\PowerWeb\PowerWeb
    lasciare il percorso proposto altrimenti scegliere questo percorso
   
    URL di Destinazione : NON inserire NULLA



    Scegliere IMPOSTAZIONI
   
    Se viene già proposto ila Configurazione RELEASE
     lasciarela Configurazione proposta
    Altrimenti sceglierela Connessione RELEASE
   
    Lasciare ON il Flag di Eliminazione tutti i files esistenti prima



   






    Premere il Tasto di PUBBLICA



Attendere che finisca e poi se si era inserito un PERCORSO LOCALE TEMPORANEO
    aprire la Cartella in cui lo si è creato
       es: C:\Massimo\Power_Web
    se su SERVER
        es:C:\Massimo\Power_Web e copiare l'intera cartella nella Cartella
        \\192.168.1.1\winit\AAA_AREA_SVILUPPO_SW\SW APPLICATIVO\PowerWeb\PowerWeb (versione utilizzata da IIS)\PowerWeb\PowerWeb
Se invece lo sie ra già creato nella Cartella di Destinazione NON SERVE FARE NULLA.

1) CASO SERVER ARCODA

  • PRIMA DI COLLEGARSI ALS ERVER ARCODA
  • Aprire la Cartella Locale
    • C:\Massimo\Power_Web
      • Aprire la Cartella DEPLOY
        • Cancellare i due Files con
          • Web.Config
          • WebConnection.Config
        • per evitare di copiarle poi sostituendole a quelle giuste che sono già sul Server Arcoda per ogni Ambiente
      • Copiare dalla Cartella
        • PowerWeb
          • PowerWeb
            • Bin
              • Le Cartelle delle Lingue
                • DE
                • .......
                • IT
                • .....
                • RU
      • nella Cartella DEPLOY
        • BIN
      • Chiudere la Cartella DEPLOY
      • ZIPPARLA ( in ZIP non /Zip e/o Rar !!!!)
  • Collegarsi al Sito ARCODA con l'Icona relativa (Arcoda.rdp)
  • SUL SITO ARCODA
    • Se sul DeskTop di Arcoda NON c'è l'Icona COMPUTER
      • premere START
        • Cliccare su Computer (in alto a Dx)
    • Aprire Computer
      • si apre una Maschera con l'elenco dei Dischi Locali e Remoti
        • selezionare C on UTENTE-PC (è il dsico C del PC di MAX)
          • selezionare la Cartella C:\Massimo\Power_Web\DEPLOY.ZIP
          • copiarlasul DeskTop del Server Arcoda
          • procedere a UNZIPPARLA
            • selezionare la Cartella Zippata con Tasto DX del Mouse
              • selezionare opzione EXTRACT ALL
          • NOTA : se serve ZIPPARE UNA CARTELLA e/O UN FILE
            • cliccare sulla Cartella/file interessata con tasto DX del Mouse
              • selezionare opzione SEND TO
                • selezionare opzione COMPRESSED FILE (zip)
        • nel caso in cui si debbano anche aggiornare Dati dei DATABASE
          • selezionare la Cartella C:\Massimo\Power_Web\AAA-Script
          • selezionare la Cartella C:\Massimo\Power_Web\AAA-QuerySql
        • se sono particolarmente GROSSI allora ZIPPARLI prime (sempre con ZIP)
        • copiare i file interessati sul DeskTop del Server Arcoda
    • Se sul DeskTop di Arcoda NON c'è l'icona ISS MANAGER
      • premere START
        • inserire IIS in cerca e attivare la ricerca
        • cliccare su PROGRAMS e INTERNET INFORMATION SYSTEMS (IIS .........)
    • si apre la relativa Maschera di Gestione
    • cliccare sul + davanti alla voce WWW-WINIT(WINIT/WinIt)
    • cliccare sulla stessa Voce (dopo averla aperta) con il TASTO DX del Mouse
      • selezionare STOP per fermare il funzionamento dei SITI
    • cliccare sul + davanti alla Voce Sites
      • cliccare sul + davanti alla Voce Power
        • per ogni Ambiente presente (PowerComo/PowerCompleto/PowerDemo/PowerIntermedio ecc ecc)
          • cliccare sulla corrispondente Voce con il Tasto dx e ripetere le seguenti operazioni
            • si apre una maschera di opzioni
              • selezionare EXPLORE
                • si apre una maschera di dettaglio
                  • NON SELEZIONARE i due Files
                    • Web.Config
                    • WebConnection.Config (può non esserci)
                  • CANCELLARE tutti gli Altri Filese e Cartelle presenti
          • aprire la cartella DEPLOY e selezionare tutte le Cartelle e Files 
            • ad ESCLUSIONE di (se ci sono ma non dovrebbero esserci perchè dovrebbero essere stati cancellati quando si è creata la Cartella)
              • Web.Config
              • WebConnection.Config
            • perchè vanno lasciate per ogni ambiente le pre-esistenti!!!
        • Ripete la sequenza per ogni Ambiente
    • Applicare gli eventuali SCRIPT e/ QUERY ai vari Database usando poi Sql Manager per farlo
    • alla fine tornare a cliccare con il Tasto DX del Mouse sulla Voce WWW-WINIT(WINIT/WinIt)
      • selezionare l'opzione START per riavviare il Sito
    • Chiudere IIS
    • Provare il funzionamento dei vari Siti Arcoda

2)CASO SERVER WINIT

VERIFICARE CHE SIA ATTIVO IL SERVIZIO SUL SERVER

  • Collegarsi al SERVER (anche in remoto).
    • Premere START
      • Inserire IIS in CERCA e attivare la ricerca
        • Cliccare su
        •     GESTIONE INTERNET INFORMATION SYSTEM
          • si apre una Maschera di Gestione
            • Cliccare su
              • WINITSERVER/WinitServer/Administrator)
                • SITI
                • verificare che il sito creato come PROFILO al Pto.1 (TestVersion )                  
                • risulti AVVIATO
                • in caso contrario procedere ad AVVIARLO
                • cliccare con il Tasto DX sul Sito che non risulta avviato
                • cliccare su Gestisci Sito Web
                •  scegliere il tasto di RIAVVIA

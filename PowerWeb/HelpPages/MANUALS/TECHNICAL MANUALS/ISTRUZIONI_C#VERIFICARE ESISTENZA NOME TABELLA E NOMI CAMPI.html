VERIFICARE NOME TABELLA E NOME CAMPI DELLE TABELLE

Quando dovesse servire verificare che
  • il Nome della Tabella che si sta usando nel programma corrisponda ad una delle Tabelle presenti nel DataBase
  • il Nome di un Campo che si sta usando nel programma corrisponda ad uno dei Campi presenti nel DataBase per la relativa Tabella
basta eseguire le seguenti istruzioni:

         //Controllo che il Nome della TABELLA inserita sia un Nome di una tabella esistente nel Dominio delle Tabelle gestite
         var currentType = Type.GetType(String.Format("Domain.{0}, Domain", entity.NomeTab));             
                if (currentType == null)
                        //nel caso in cui risponda NULL significa che il Nome indicato non esiste nel Dominio delle Tabelle conosciuto dall'applicativo
                       throw new Exception();  // oppure aggiungo il messaggio di errore al Dictionary ecc.ec

            //Dopo aver vevrifica e quindi ottenuto la Tabella in currentType
            //Controllo che il Nome del Campo sia un Nome di uno dei Campi della Tabella indicata
            var property = currentType.GetProperty(entity.NomeCampo);
                if (property == null)
                    //nel caso in cui risponda NULL significa che il Nome del Campo NON appartiene alla Tabella indicata
                    throw new Exception();

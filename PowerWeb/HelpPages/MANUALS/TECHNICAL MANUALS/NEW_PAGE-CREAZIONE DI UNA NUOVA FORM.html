CREAZIONE DI UNA NUOVA FORM

Aprire la Soluzione di PowerWeb con VisualStudio (PowerWeb.sln )

1)  REPOSITORY
  • SOLUTION
    • BUSINESS
      • REPOSITORY
        • CUSTOM
  • Seleziona un IRepository esistente
    • es: IFruRepository.cs
    • COPIA
    • INCOLLA
      • es: Copia di IFruRepository.cs
    • RINOMINA
      • es: IPruRepository.cs
    • Aprire il Nuovo IRepository
      • es IPruRepository.cs
      • che contiene le funzioni da Richiamare (minimo la INIT)
      • SOSTITUIRE tutti i Nomi riferiti alla vecchia Form ( es: Utenti)
        • con i Nomi della NUOVA FORM (es: PRU)
  • Selezionare il relativo Repository all'interno di IRepository 
    • es: IPruRepository.cs
      • FruRepository Copia di .cs che ha ancora il Vecchio NOME!!
    • Per Poter CAMBIARE il Nome della Sottoclasse FruRepository Copia di .cs
      • occore separare il Gruppo IPruRepoitory.cs/FruRepository-Copia.cs
      • Selezionare la Sottoclasse FruRepository-Copia.cs
        • Tasto DX del Mouse
          • Selezionare UnGroupItems
      • Cambiare il Nome della Sottoclasse FruRepository-Copia.cs in PruRepository.cs
    • Raggruppare la Sottoclasse PruRepository.cs sotto alla Classe IPruRepository.cs
      • Selezionare la Classe IPruRepository.cs e la Classe PruRepository.cs 
        • tenendo premuto CTRL + Mouse
        • Premere Tasto dx del Mouse
          • Selezionare GroupItems
            • Specificare che la Root sara IPruRepository.Cs
    • Aprire il Codice di FruRepository.cs
    • SOSTITUIRE tutti i vecchi Nomi ( es: Utenti)
      • con i Nomi  (es: PRU)
    • MODIFICARE la Class INIT 
      • inserirci tutti i Campi che vanno inizializzati con dei Valori di Default
            •  es: public Pru Init()   
                    Pru currentUser = new Pru()
                    {
                      DisAbilitazione_Pru = false,
                      Data_Registrazione_Pru = DateTime.UtcNow,
                      DataOraUltimaModifica_Pru = DateTime.UtcNow,
                    };
                    return currentUser;    
    • MODIFICARE la Class CHECK (gestisce i Controlli)
      • restituisce un Dictionary con le coppie Nome Campo / Messaggio di Errore (quando ci sono errori)
      • inserire tutti i Controlli da eseguire sulla Entità trattata.
          • Copiandoli da POWER_S e modificandoli opportunamente

.3)  INFRASTRUCTURE
  • SOLUTION
    • BUSINESS
      • INFRASTRUCTURE
        • Apri UnityDependencyResolver.cs
  •  Aggiungere la Riga di Codice necessaria a gestire il Riferimento al Repository appena definito
    • Aprire l'eventuale #Region UTILITIES (se chiusa)
      • nella  private void ConfigureContainer(IUnityContainer container)
        • nel gruppo di apparteneza
          • Gruppo dei Repository CUSTOM
            • container.RegisterType<IPruRepository, PruRepository>(new UnityPerExecutionContextLifetimeManager());
          • Gruppo dei Repository GENERIC 
            • container.RegisterType<IRepository<Menu_Tipo>, GenericRepository<Menu_Tipo>>(new UnityPerExecutionContextLifetimeManager());

5) PAGES
  • SOLUTION
    • POWERWEB
      • PAGES
  • Copiare la Nuova Pagina da una esistente con la stessa struttura 
    • es: Fru.aspx
    • COPIA
    • INCOLLA 
      • es: Copia di Fru.aspx
    • RINOMINA
      • es: Pru.aspx
  • Aprire il Codice Html della Pagina (facendo DOPPIO CLICK  sul Nome della Pagina (es:Pru.aspx))
    • Modificare i Riferimenti da Vecchi Nomi a Nuovi
      • <%@ Page Title="" Language="C#" MasterPageFile="~/GridMasterPage.master" AutoEventWireup="true"
            CodeBehind="Pru.aspx.cs" Inherits="PowerWeb.Pages.Fil" %>
      • <%@ Register TagPrefix="pw" TagName="PruModule" Src="~/Modules/PruModule.ascx" %>
      • <asp:Content ID="Content1" ContentPlaceHolderID="HeadContent" runat="server">
      • </asp:Content>
      • <asp:Content ID="Content2" ContentPlaceHolderID="MainContent" runat="server">
        • <pw:PruModule runat="server" ID="mdlPruModule" />
      • </asp:Content>
  • Aprire il Codice Source della Pagina (Selezionando la Pagina (es:Pru.aspx) e facendo Visualizza Codice
    • Sostituire TUTTI VECCHI NOMI DEI RIFERIMENTI CON I NUOVI NOMI
  • Salvare la Pagina
6) AGGIUNGERE NUOVA RISORSA

    • COMMON
      • PowerWebResources.resx
        • con nome : MENU_NOMEFUNZIONE_TEXT
  • Altrimenti aggiungerla nel formato 
7) LANCIARE COMPILAZIONE
  •   Premere F6 x lanciare Compilazione
8) AGGIUNGERE UN NUOVO RECORD in Tabella TAB_FUNZ nel DataBase SQL  
  • Aprire il DataBase SQL
  • Aggiungere nel DataBase SQL un Nuovo Record in Tabella TAB_FUNZ
    • Selezionare la Tabella TAB_FUNZ
      • Fare Click con Tasto DX del Mouse sula Tabella TAB_FUNZ
        • Cliccare su opzione MODIFICA PRIME XXXXX RIGHE
          • Copiare da un Record esistente un Nuovo Record 
          • Cambiare il valore del Campo LINK inserendoci quello della Nuova Pagina nel seguente formato Es: ~/Pages/Resp.aspx
          • Cambiare il valore del Campo TAB_FUNZ_NOME inserendoci quello della Nuova Risorsa 
            • MENU_NOMEFUNZ_TEXT

          • Copiare da un Record esistente un Nuovo Record 
          • Cambiare il valore del Campo LINK inserendoci quello della Nuova Pagina nel seguente formato Es: ~/Pages/Resp.aspx
          • Cambiare il valore del Campo TAB_FUNZ_NOME inserendoci quello della Nuova Risorsa

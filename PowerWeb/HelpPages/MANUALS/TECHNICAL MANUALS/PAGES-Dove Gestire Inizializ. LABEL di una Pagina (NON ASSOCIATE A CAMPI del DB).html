Dove Inizializzare le LABEL di una Pagina (NON ASSOCIATE A CAMPI del DB)

Le Label dei Campi definiti nel DATABASE vengono automaticamente gestite e caricate in Lingua dal Sistema (vedi xxxxx)

Nel caso delle eventuali LABEL "slegate" dai corrispondenti campi, come ad esempio per le Label della Pagina di LANCIO ELABORAZIONE, queste label vanno INIZIALIZZATE (sempre in lingua) insernedone le relative Istruzioni nel Codice ascx del corrispondente Modulo e più precisiamente in
  • POWER WEB
    • MODULES
      • XXXXModule.ascx.cs  (vedi ad esempio Modulo ELABORATEMODULE.ascx.cs)
        •  protected void Page_Init(object sender, EventArgs e)
                  {          
                       //Inizializza le Label della Pagina Video in Lingua  

                      lblFileDaImportare.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_IMPORT_TXT);
                      btnUpload.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_IMPORT_TXT);
                      lblDal.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_PERIODO_DAL);
                      lblAl.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_AL);
                      btnTrips.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_LANCIO_ELAB_VIAGGI);
                      btnElaborate.Text = CommonServiceBiz.GetLocalizedString(PowerWebResources.LBL_LANCIO_ELAB_REG);
                      lblResult.Text = ".";
                      //Inizializza la Data Inizio Elaborazione con la Data del 1° del Mese Precedente
                      deFrom.Date = new DateTime(DateTime.Today.Year, DateTime.Today.Month, 1).AddMonths(-1);

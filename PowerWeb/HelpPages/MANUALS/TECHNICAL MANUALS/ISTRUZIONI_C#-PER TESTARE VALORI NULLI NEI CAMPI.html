ISTRUZIONI X TESTARE PRESENZA VALORI NULLI NEI CAMPI

  • NULLABLE
    • STRING 
      • if ( String.IsNullOrEmpty(Entity.xxxxxxx)) ---------------> restituisce True/False
    • INT / DOUBLE / FLOAT / DATETIME / TIME (x) / TIMESPAN ? (nullable)
      • if ( Entity.xxxxxxxxx.HasValue)                ----------------> restituisce True/False                      
  • NOT NULLABLE
    • STRING 
      • if ( String.IsNullOrEmpty(Entity.xxxxxxx)) ---------------> restituisce True/False
    • INT (not nullable)
      • if ( Entity.xxxxxxx == Int32.MinValue)     ----------------> restituisce True/False
    • DOUBLE (not nullable)
      • if ( Entity.xxxxxxx == Double.MinValue)     ----------------> restituisce True/False
    • FLOAT(not nullable)
      • if ( Entity.xxxxxxx == Float.MinValue)     ----------------> restituisce True/False
    • DATETIME(not nullable)
      • if ( Entity.xxxxxxx == DateTime.MinValue)     ----------------> restituisce True/False
    • TIMESPAN(not nullable)
      • if ( Entity.xxxxxxx == TimeSpan.MinValue)     ----------------> restituisce True/False

DOVE GESTIRE LE CASCADE delle COMBOBOX

Nel caso in cui si voglia che la scelta di un Record presente nell'elenco dei Record associati ad una CompoBox provveda in "cascade"
a riempire automaticamente altri campi della maschera come ad esempio fare sì che la scelta del Luogo di Residenza faccia riempire
anche i corrispondenti Campi Video del CAP e della Provincia associati al Luogo selezionato nella Lista associata alla ComoBox del
campo Luogo di Residenza occorre aggiungere, per ogni campo per il quale si vuole gestire la "cascade",

NEL CASO DI UN MODULO CON FORM SINGOLA (Cant,Col;Cli;Fru;Pru, ecc)
  le seguenti istruzioni in
  • POWERWEB
    • MODULES
      • CliModules.ascx
        • function OnDomLuogoChanged(s, e)
              {
                  var currentCmb = ASPxClientComboBox.Cast(s);
                  var domProvCmb = ASPxClientComboBox.Cast(grid.GetEditor("Domicilio_Provincia_Cli"));
                  var domCapCmb = ASPxClientComboBox.Cast(grid.GetEditor("Domicilio_Cap_Cli"));
                  domProvCmb.SetValue(currentCmb.GetSelectedItem().GetColumnText("Codice_Prov_Tab_Comuni"));
                  domCapCmb.SetValue(currentCmb.GetSelectedItem().GetColumnText("Cap_Tab_Comuni"));
              }
    • e conseguentemente le relative istruzioni che la richiamana anche nel Modulo
      • CliModules.ascx.cs
        •  protected void Page_Init(object sender, EventArgs e)
          • vanno aggiunte le seguenti istruzioni per ogni Campo di cui si vuole gestire la Cascade di uno o più valori presenti nella sua ComboBox negli "n" campi corrispondenti (definiti in aspcx a fronte dell'evento OnxxxChanged
            • GridViewDataComboBoxColumn domLuogo = gvCli.Columns["Domicilio_Luogo_Cli"] as GridViewDataComboBoxColumn;
                          domLuogo.PropertiesComboBox.ClientSideEvents.SelectedIndexChanged = "OnDomLuogoChanged";
NEL CASO DI UN MODULO CON FORM DETTAIL (Fru_Cant,Pru_Col;Cant_Note;COl_Note, ecc)
  le seguenti istruzioni in
  • POWERWEB
    • MODULES
      • Fru_CantModules.ascx
        • function OnCodice_CantiereChanged(s, e) {
                  var currentCmb = ASPxClientComboBox.Cast(s);
                  var codice_CantiereCmb = ASPxClientComboBox.Cast(detailGrid.GetEditor("Descrizione_Can"));
                  codice_CantiereCmb.SetValue(currentCmb.GetSelectedItem().GetColumnText("Descrizione_Can"));
              }
    • e conseguentemente le relative istruzioni che la richiamana anche nel Modulo
      • Fru_CantModules.ascx.cs
        • protected void gvFru_Cant_Detail_BeforePerformDataSelect(object sender, EventArgs e)
                  {
                      ASPxGridView gvDetails = sender as ASPxGridView;
                      if (gvDetails != null)
                      {
                          CommonServiceWeb.FillGridLabels(typeof(Fru_Cant), gvDetails);
                          CommonServiceWeb.FillComboboxes(gvDetails);
                          CommonServiceWeb.InitDetailGrid(Page, gvDetails);
            • vanno aggiunte le seguenti istruzioni per ogni Campo di cui si vuole gestire la Cascade di uno o più valori presenti nella sua ComboBox negli "n" campi corrispondenti (definiti in aspcx a fronte dell'evento OnxxxChanged
              • GridViewDataComboBoxColumn codCant = gvDetails.Columns[CommonService.GetPropertyName(() => _cantStub.Cant_Id)] as  GridViewDataComboBoxColumn;
              •  codCant.PropertiesComboBox.ClientSideEvents.SelectedIndexChanged = "OnCodice_CantiereChanged";
            • alle pres-esistenti istruzioni
            • BindDetailGrid(gvDetails);
                          }
                      }
                                NOTA BENE :
  • Nel caso in cui NON VENGA SCELTO NESSUN RECORD fra quelli esistenti e proposti nella COMBOBOX
    • ma venga "editato" manualmente un Valore che non esiste (quando la cosa è permessa)
      •  allora la "cascade" NON VIENE ATTIVATA
  • Nel caso in cui i campi che devono essere riempiti in "cascade" abbiano già dei valori
    • i vecchi valori VENGONO SOSTITUITI CON I NUOVI associati al Nuova Volare selezionato nella ComboBo

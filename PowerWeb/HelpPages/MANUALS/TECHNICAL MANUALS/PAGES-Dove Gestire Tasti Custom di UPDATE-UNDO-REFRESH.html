Dove Gestire i Tasti Custom di UPDATE/UNDO/REFRESH

I tasti di UPDATE e di UNDO sono definiti e gestiti in Modo CUSTOM per Tutte le Pagine di EDIT delle MASTERGRID  e/o DETAILGRID
mentre il Tasto di REFRESH è (per adesso) gestito e abilitato SOLO per le specifiche Griglie GVREG_V e GVREG_VM.

Il Tasto di Refresh permette in particolare di Gestire
  •        dei Calcoli (basati sui dati disponibili a Video)
    • es: per le GvReg_V e GvReg_VM esegue il ricalcolo della Durata Fisica della Registrazione
  •        di Cambiare/Annullare i Valori dei Campi a Video (basandosi solo sui valori dei campi disponibili a Video)
    • es: per le Gvreg_V e GvReg_VM azzera i valori dei Campi che in caso di Modifica dei Dati a Video non sono più validi
  •        di NON Mostrare + determinati Campi dopo il Refresh
    • es: per le GvReg_V e GvReg_VM ELIMINA DALLA PAGINA VIDEO i campi i cui valori in caso di Modifica dei dati a Video non sono più validi
Ad ogni Tasto e in base al fatto che sia una masterGrid o una DetailGrid vengono anche associati degli eventi CUSTOM al Click e in particolare
vengono associati i seguenti eventi Custom
  • Tasto di UPDATE
    • NUOVA RIGA (Inserimento)
      • MasterGrid
        • OnCustomNewTemplateButtonClick
      • DetailGrid   
        • OnCustomNewTemplateButtonDetailClick
    • RIGA ESISTENTE (Aggiornamento)
      • MasterGrid
        • OnCustomEditTemplateButtonClick
      • DetailGrid   
        • OnCustomEditTemplateButtonDetailClick

  • Tasto di UPDATE (UNDO)
      • MasterGrid
        • OnCustomCancelTemplateButtonClick
      • DetailGrid   
        • OnCustomCancelTemplateButtonDetailClick

  • Tasto di REFRESH (x Adesso SOLO x GVREG_V e/o GVREG_VM)
      • MasterGrid
        • OnCustomRefreshTemplateButtonClick
      • DetailGrid   
        • OnCustomRefreshTemplateButtonDetailClick

  1. function doCustomRefreshButtonClick(currentGrid) {
            /*esegue le operazioni richieste dalla pressione del Tasto di Refresh
              AL MOMENTO VIENE GESTITO SOLO per le GVREG_V e GVREG_VM
              Per le quali esegue il RICALCOLO DELLA DURATA FISICA (tenendo conto della possibilità che l'Uscita sia < dell'Entrata (Notturno)
              SE IN FUTURO IL TASTO DI REFRESH VERRA' ATTIVATO ANCHE SU ALTRE PAGINE
              BASTERA' AGGIUNGERE UN IF SUL NOME DELLA GRID CHE SI STA TRATTANDO*/
            currentGrid = ASPxClientGridView.Cast(currentGrid);
            //Ricalcolo a Video della Durata Fisica
            var fisE = currentGrid.GetEditValue("Data_Ora_Fis_E");
            var fisU = currentGrid.GetEditValue("Data_Ora_Fis_U");
            var length = "0000";
            if (fisU != null && fisE != null) {
                var hourDiff;
                var minuteDiff;
                var backwards = false;
                if (fisU > fisE) {
                    hourDiff = fisU.getHours() - fisE.getHours();
                    minuteDiff = fisU.getMinutes() - fisE.getMinutes();
                } else {
                    hourDiff = (24 - fisE.getHours()) + fisU.getHours();
                    minuteDiff = (0 - fisE.getMinutes()) + fisU.getMinutes();
                    backwards = true;
                }
                length = getTimeSpanStringFromDateDiff(hourDiff, minuteDiff, backwards);
            }
            /*ANNULLA I VALORI DEI CAMPI I CUI VALORI SARANNO POI RICALCOLATI
            QUESTA PARTE E' STATA LASCIATA x DOCUMENATZIONE in quanto poi gli Stessi CAMPI VENGONO ELIMINTAI DAL VIDEO*/
            currentGrid.SetEditValue("Durata_Fis_HH_S", length);
            currentGrid.SetEditValue("Registrazione_Stato_Reg", null);
            currentGrid.SetEditValue("Registrazione_Tipo_Reg", null);
            currentGrid.SetEditValue("Tipo_Modifica", null);
            currentGrid.SetEditValue("RiferimentoRRN_Att", null);
            currentGrid.SetEditValue("Durata_Fig_HH_S", null);
            currentGrid.SetEditValue("Data_Ora_Fig_E", null);
            currentGrid.SetEditValue("Data_Ora_Fig_U", null);
            /*Elimina dalla Pagina Video i CAMPI che non devono + essere mostrati in quanto i loro valori verranno ricalcolati*/
            currentGrid.GetEditor("Registrazione_Stato_Reg").SetVisible(false);
            currentGrid.GetEditor("Registrazione_Tipo_Reg").SetVisible(false);
            currentGrid.GetEditor("Tipo_Modifica").SetVisible(false);
            currentGrid.GetEditor("RiferimentoRRN_Att").SetVisible(false);
            currentGrid.GetEditor("Durata_Fig_HH_S").SetVisible(false);
            currentGrid.GetEditor("Data_Ora_Fig_E").SetVisible(false);
            currentGrid.GetEditor("Data_Ora_Fig_U").SetVisible(false);
        }

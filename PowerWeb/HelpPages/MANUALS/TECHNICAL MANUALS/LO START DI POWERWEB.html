LO START DI POWERWEB

Quando PowerWeb viene lanciato per PRIMA COSA viene attivata la
  • All'interno della Global.ascx.cs
    • la routine Application_Start
      • che richiama all'interno della Region Methods della Business.PowerWebConfig.cs
        • la routine Init
          • che se NON è la prima Attivazione del Giorno
            • richiama la routine  Create
              • che recupera dalla WebConnection.config
                • la stringa di connessione al DB SQL
              • registrando che NON è più la Prima Conenssione
  • e poi all'interno della Site.Master.cs
    • richiama la Page_Init
      • che provvede a Inizializzare il Titolo ed il Sottotitolo dell'Applicazione
        • prendendoli dai campi STR_TITOLO e STR_TITOLO_SUB delle Resources
  • e poi all'interno della Default.Aspx,cs
    • la routine Page_Init
      • che gestisce il Controllo sulla Data di Scadenza e sulla Data Ultimo Controllo
        • se non trova il File \Scripts\Debug.txt
          • che segnala di NON eseguire il controllo (quando si è in TEST)
        • chiama all'interno della Business.BusinessServices.cs
          • la routine CheckFirstTimeInitialize
            • che verifica esista il File ( il cui nome [menu2.js] è preso dal campo LastConn dei SETTINGS ) contenente criptata la Data dell'Ultima Connessione fatta
            • decriptandone il valore con la routine MD5DescryptStrin
            • decripatando poi il valore della Data Attuale del Server sul quale è stato attivato PowerWeb
            • se la Data/Ora Attuale del Server sul quale è stato attivato POWERWEB è MINORE/UGUALE alla Data/Ora dell'Ultima Connessione fatta
              • Genera una ECCEZIONE
            • Se la Data (senza Ora) Attuale del Server sul quale è stato attivato POWERWEB è UGUALE alla Data (senza Ora) dell'Ultima Connessione fatta
              • significa che i controlli per quel giorno sono stati già fatti e quindi prosegue senza farne altri
            • Se la Data (senza Ora) Attuale del Server sul quale è stato attivato POWERWEB è MAGGIORE alla Data (senza Ora) dell'Ultima Connessione fatta
              • Registra la Nuova Data di Ultimo Collegamento nel File il cui nome [menu2.js] è preso dal campo LastConn dei SETTINGS
              • richiama poi la routine UpdateExpirationDate
                • che richiama la IsExpired
                  • che richiama la GetExpirationDate
                    • provvede a richiamare il Servizio di Gestione Licenze della Winit passandogli
                      • la PublicKey del Cliente /recuperandola dalla Tab PARAM)
                      • la Data di Ultimo Colllgamento
                    • ricevendone indietro
                      • la Nuova ActivationDate registrata per quella PublicKey nel DB del Servizio Gestione Licenze Winit
                    • oppure NULL ad indicare che la Licenza è scaduta
                  • ADESSO IMPOSTA INVECE  AUTOMATICAMENTE LA DATA DI EXPIRATION A MAX VALUE 
                • e verifica che la Nuova Data di Scadenza ricevuta sia MAGGIORE/UGUALE alla Data Attuale del Server sul quale è stato attivato PowerWeb
        • altrimeni CHIUDE l'APPLICAZIONE
      • Calcola quanti Giorni Mancano alla Nuova Data di Scadenza  ricevuta
        • Se i Giorni rimanenti sono INFERIORI al N° di GG presenti nel campo GiorniAvvisoScadenza dei SETTINGS
          • mostra a Video un messaggio di avviso indicando quanti GG mancano ancora alla Scadenza.
    • la routine Page_Load
      • che recupera dal campo CompanyName della tab PARAM il Nome della Società da mostrare a video
  • e poi all'interno della Site.Master.cs
    • richiama la Page_Load
      • ATTUALMENTE VUOTA
Il Nome della pagina di Iniziale di AUTENTICAZIONE dell'Utente viene preso dalla WEB,CONFIG.                                   
  • <authentication mode="Forms">
    • <forms loginUrl="~/Account/Login.aspx" timeout="2880" />
  • </authentication>

  • della Account.Login.aspx.cs

        • la relativa Password

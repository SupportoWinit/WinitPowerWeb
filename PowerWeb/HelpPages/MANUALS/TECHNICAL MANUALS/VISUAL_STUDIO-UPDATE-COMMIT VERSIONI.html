GESTIONE DELLE VERSIONI

La Sincronizzazione delle Versioni di PowerWeb avviente utilizzando il SW gratuito TORTUOISE

1)  PRIMA DI INIZIARE UNA MODIFICA
  • Aprire la Soluzione di PowerWeb con VisualStudio (PowerWeb.sln
    • Selezionare SOLUZIONE "POWERWEB"  e premere Tasto DX del Mouse




   
      • Selezionare l'opzione Update Solution to Latest Version
    • verificare che NON vengano segnalati problemi fra le versioni

2)  A QUESTO PUNTO SI PUO' INIZIARE A MODIFICARE LA SOLUTION

3)  DOPO AVER TERMINATO UNA MODIFICA
  • Occorre riprendere le EVENTAULI Modifiche eseguite da altri e presenti sul Server
    • Selezionare SOLUZIONE "POWERWEB"  e premere Tasto DX del Mouse




   
      • Selezionare l'opzione Update Solution to Latest Version
      • Verificare che NON vengano segnalate modifiche fatte da altri sugli stessi Moduli che si sono modificati localmente
      • Salvare la propria Versione sul Server selezionado l'opzione
        • COMMIT SOLUTION CHANGES
        • Scrivere nel LOG un breve testo esplicativo di quanto fatto nella Versione
4) PER VISUALIZZARE LA STORIA DELLE MODIFICHE FATTA ALLA SOLUZIONE e/o al Singolo ELEMENTO
  • Selezionare la Soluzione e/o il Singolo Elemento con il Tasto DX
    • Scegliere l'opzione View History
5)  PER RIPRISTINARE UN ELEMENTO ALL'ULTIMA VERSIONE SALVATA SUL SERVER (perdendo le eventuali modifiche fatte localmente)
  • Selezionare il Singolo Elemento che si vuole riportare indietro alla Versione Salvata con il Tasto DX
    • Scegliere l'opzione Revert
